# 决策与报告规格

## 阅读结构

1. **首屏结论**：当前经营问题、优先动作、交付批次、证据强度。标题写行动和对象，不写“深度洞察”或只报分析了多少条。
2. **制作方案**：默认 3 方向，分别写购买顾虑/场景、核心表达、结构、证据参考和验证假设；优先方向给时间段、画面、声音/文字、素材、AI 可做部分、实拍要求。
3. **承接方案**：按已知渠道给商品页/商品卡/主页等动作；谁补什么信息，如何和广告一致。未审计页面不诊断现状。
4. **测试复盘**：同一变量的版本与匹配条件、所需数据、不同表现对应的下一步。暂不做什么也要具体。
5. **决策图表**：2–4 张有用图即可；逐张写问题、口径、判断、行动、边界。数据不足宁可缩减。
6. **案例并排**：每条只强调借什么、问题是什么、对本产品怎么改，链接至原片时间。
7. **证据区**：真实原片播放器、前 5 秒逐秒图、后续关键图、声画对应、结尾、音轨转写与缺口。截图可放大。
8. **来源附录**：素材清单、原表分析、指标定义、日期/时区、缺失/疑点、原片读取状态。

可根据用户要求调整层级；不会强制所有任务采用独立站或同一漏斗。报告可以很长，但不能让读者读完大量分析才能找到行动。

## 好的结论单元

`现在改什么 → 原片/数据事实 → 对当前产品的推理 → 谁交付什么 → 用什么观察验证 → 仍未知什么`

“某条播放最高”只帮助选参考；不能成为“照拍同样时长/追加预算”的依据。“若广告主卖点在中段才出现，则测试前置”比“黄金三秒很重要”更可执行。不要固定要求每条都“结构揭示”，商品不同应改为相应可验证的购买理由。

## 图表选择

- 类型分布：仅支持参考池/素材资产结构判断；不能把参考池缺口说成品牌缺口。
- 播放与互动分布：用于选样、发现异常与观察差异，不能推导成交。
- 时间线：展示重要信息首次出现位置，支持具体重排镜头；原片时间和提议时间分别标识。
- 自有广告数据可用漏斗、成本与转化分组：仅在口径/样本可比时进行表现比较；明确归因窗口与自然/付费区别。
- 不要为了美观给未知漏斗填假数、自己发明商业评分或通用合格线。

## 独立站场景的可选复盘框架

| 观察 | 检查 | 动作 |
|---|---|---|
| 前段留存和外链点击均弱 | 产品/理由是否看懂、受众版位 | 固定中后段，换开头 |
| 留存不错，点击弱 | 内容是否只有审美，商品和 CTA 是否明确 | 锁定 SKU，补购买理由 |
| 点击不错，到站弱 | URL、加载、追踪和设备差异 | 先验证技术与测量，不先怪创意 |
| 到站有量，加购弱 | 广告页面一致性、选码、价格、可售性 | 查页面和顾虑，再安排补拍 |
| 加购有量，购买弱 | 运费、配送、结账、支付、库存 | 用真实流程证据修复交易环节 |
| 可归因购买出现 | 样本、窗口、退款与可接受获客成本 | 结合经营目标决定继续观察或加量 |

这只是检查顺序，不是自动诊断树。同一现象可有多种原因。到站/点击可存在不同口径；站内加购比例明确是事件数还是会话数。广告来源参数按平台当前支持方式，不能自称已部署追踪。

## AI 分工

可承担脚本、转写、字幕对齐、粗剪、版式、素材分类和有事实依据的语言适配。产品结构、真实体验、功能测试、评价和尺码结果须有真实素材；不能让生成试穿冒充实测。未指定市场时不默认英文，也不继承上个案例的模特或优惠。

## 退化交付

- 全部视频不可读：给数据可用性与暂定测试框架，显著写“原片未核验”，不生成假截图或完整镜头诊断。
- 只有视频无数据：完成内容与制作分析，图表可用真实时长/时间线，明确没有表现比较依据。
- 表格部分读取：标已读/预期/缺失及原因；不声称全量。
- 缺浏览器：静态验收与未验项分开，保留可交付文件。

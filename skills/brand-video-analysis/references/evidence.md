# 数据与媒体核验

## 数据读取

字段按含义映射，不复用旧 fieldId：素材 ID/原帖、作者、发布时间、采集时间、播放/曝光、互动、时长、标签、已有分析、附件与下载来源；有账户数据时另记消耗、点击、到站、加购、购买及归因口径。缺失保持 null，零保留为零；计算前处理文本型数字、单位和异常值，不默默改“异常”原值。

表格分页要核对唯一记录数和分页终止；有预期 ID 集合时逐项比较。钉钉曾出现超过 20 个 ID 的回读静默截断：发现数量不符就按至多 20 个已知 ID 回读，不以 hasMore=false 单独保证完整。飞书导出要对比实际可解析对象数与 manifest。首个工具错误后读对应精确契约，不盲猜命令、ID 或认证。

清单至少包括：`asset_id, record_id, original_post, data_timestamp, metrics, source_type(自有/竞品/不明), selected_reason, media_status, audio_status, local_video, sha256, duration, frames[]`。可从同一记录关联附件与成绩；标题相近或文件时间相邻不是关联证据。未知归属保留待核。

## 下载与查看

优先读取已授权表格中的视频附件或对应下载字段。在工具允许的环境下载已知媒体，不绕过登录/付费/权限。先确认 HTTP/大小/解码，再看样本帧与记录身份；200 和 .mp4 后缀不保证是真视频。临时 URL 仅在进程内消费，原始快照放内部目录。

代表样本默认 3–5 条：最相关的产品解释、相对高表现、不同结构、反向/不足案例。不是机械取播放前五。先写选择原因并保留未选状态。选中的视频若无法读取，可以补选可读案例，但仍在清单记录失败原因；不能用表内 AI 描述冒充实际观看。

## 抽帧与音轨

```bash
python3 <技能目录>/scripts/extract_evidence.py --video <已下载原片> --id v01 --out <报告目录>/assets/v01 --scan-step 3
# 看联系表后，以真实时间补关键帧；同一视频可安全复跑，已存在截图跳过。
python3 <技能目录>/scripts/extract_evidence.py --video <已下载原片> --id v01 --out <报告目录>/assets/v01 --key-times 8,11.2,16
# 可选：存在 faster-whisper 和本地缓存模型时，用真实音轨转写。
python3 <技能目录>/scripts/extract_evidence.py --video <已下载原片> --id v01 --out <报告目录>/assets/v01 --asr-model small --language en
```

脚本依赖 ffmpeg/ffprobe，联系表可用 Pillow；ASR 可选依赖 faster-whisper，默认 local_files_only，不自动下载模型。按宿主已有运行时选择 Python，缺依赖时隔离安装并优先可用国内镜像，不能全局改依赖或启动服务。也可用宿主其他可靠转写工具。

初始扫描不是剪辑边界识别。前 0–5 秒全取，后段抽样用于找转折；人工补关键动作、字幕切换、CTA 与实际尾帧。抽取结尾先检查视频流时长；容器时长可能由更长音轨决定，按容器末尾寻帧会得到空文件。保留容器和视频流两个时长，核对实际可解码帧。接近末尾时确认不是片尾黑场遮掉最后信息。视情况查看连续播放，不能仅凭静帧计算切镜速度或评价音乐卡点。

画面、口播、上屏字幕和帖文分列。ASR 时间是近似值，专名和同音词应与字幕/语境核对，保留原转写及校正说明。音乐中的歌词不等于卖点口播。没有读音轨时不得照抄源表“无口播”。既有 AI 分析与原片冲突时，以可验证原片为准，在报告明确纠正。

## 原片事实与营销主张

- 洗衣动作只能证明展示了洗衣；没有控制条件与尺寸对比，不能证明不缩水。
- 拉伸只能支持看见面料在该动作下形变，不能证明全天舒适或支撑等级。
- 模特“我很喜欢/很舒服”是其体验陈述，不等于普遍效果。
- 同一模特的四套穿搭不是四种身形试穿。
- 视频 CTA、帖子 CTA、商品页购买能力分别记录。
- 不同发布天数、作者、自然/付费流量未知的样本，不能解释表现差异的因果。
